# Guía de despliegue para Codex
Consulta https://supabase.com/docs y https://vercel.com/docs antes de actuar. Comprueba versiones y ayuda CLI. No asumas flags válidos. Usa proyecto y organización confirmados. Separa URI de migraciones y runtime. Obtén URI y CA de Supabase Connect; configura secretos directamente en entorno del backend. Usa pool transaccional para funciones serverless, sin prepared statements nombrados. No uses credenciales administrativas como runtime. Verifica red, TLS y permisos. Revisa migraciones y dry-run disponible; no resetees producción. En Vercel comprueba runtime Node, Argon2id, routing, cookies, protección CSRF y límites persistentes. Despliega solo con autorización. Guarda URL y smoke tests sin secretos.
